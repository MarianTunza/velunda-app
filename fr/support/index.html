Nous écrire

Mon journal n’apparaît pas sur mon autre appareil

  • Les deux appareils doivent utiliser le même compte Apple, avec iCloud activé.
  • Ouvrez Velunda sur les deux en étant connecté à Internet et patientez une minute : les modifications se synchronisent en arrière-plan.
  • Dans Velunda, Réglages > iCloud indique l’état de la synchronisation, par exemple si votre stockage iCloud est plein.

J’ai acheté Velunda, mais il paraît verrouillé

Ouvrez la page de déverrouillage (Réglages > Achat) et touchez Restaurer l’achat. Vérifiez que l’App Store de cet appareil utilise le compte Apple avec lequel vous avez acheté. Avec le Partage familial, votre famille profite aussi de Velunda.

La semaine offerte

Velunda vous offre sept jours avec tout inclus. Ensuite, le déverrouiller se fait en un seul achat : sans abonnement. Quoi que vous décidiez, tout ce que vous avez écrit reste à vous : à relire, à rechercher et à exporter.

Photos et lieux

Une page peut contenir jusqu’à dix photos. Quand une photo comporte une position, Velunda indique sous la date la ville où elle a été prise ; sans connexion, la ville est ajoutée plus tard. Vous pouvez retirer une ville d’une page, ou désactiver cette option dans Réglages > Ajouter les lieux des photos.

Enregistrements vocaux

Chaque page peut contenir jusqu’à cinq enregistrements de trois minutes au maximum. Si l’enregistrement ne démarre pas, autorisez l’accès au micro pour Velunda dans l’app Réglages. Velunda transcrit ce que vous avez dit sur votre appareil, dans les langues que votre iPhone ou votre iPad prend en charge pour cela ; la première fois, votre appareil peut avoir besoin de télécharger le modèle vocal d’Apple.

Garder une copie de votre journal

Réglages > Exporter le journal vous permet d’enregistrer une sauvegarde (à réimporter), des fichiers Markdown, un PDF, ou les trois dans une seule archive. Le livre de l’année se trouve dans Rétrospective.

J’ai supprimé une page par erreur

Les pages supprimées restent dans Suppressions récentes (Réglages > Suppressions récentes) pendant 30 jours. Ouvrez-en une et touchez Récupérer.

Verrouillage de l’app

Si Face ID ou Touch ID ne fonctionne pas, vous pouvez toujours déverrouiller avec le code de l’appareil. Le verrouillage nécessite qu’un code soit défini sur l’appareil.
